# راه‌اندازی فاوا رادیو روی Render

## قبل از شروع
- برای آزمایش: حساب GitHub و Render، Node.js 20+ و پروژهٔ LiveKit Cloud.
- Render رایگان برای آزمایش مناسب است، نه سرویس بی‌سیم ۲۴ ساعته. وب‌سرویس رایگان پس از ۱۵ دقیقه بی‌ترافیکی می‌خوابد و PostgreSQL رایگان Render پس از ۳۰ روز منقضی می‌شود.

## مراحل
1. کل پوشهٔ پروژه را در یک مخزن GitHub جدید بارگذاری کنید.
2. در Render یک PostgreSQL بسازید و آدرس داخلی اتصال آن را کپی کنید.
3. یک Web Service از مخزن بسازید. دستورات Build و Start در فایل `render.yaml` آمده‌اند.
4. متغیرهای محیطی را تنظیم کنید:
   - `DATABASE_URL`: آدرس PostgreSQL
   - `JWT_SECRET`: یک رشتهٔ تصادفی بلند (حداقل ۳۲ کاراکتر)
   - `ADMIN_BOOTSTRAP_USERNAME`: `admin`
   - `ADMIN_BOOTSTRAP_PASSWORD`: رمز قوی حداقل ۱۲ کاراکتری
   - `INVITE_CODE`: کد محرمانه برای ثبت‌نام کاربران
   - `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`: اطلاعات پروژه LiveKit
5. پس از استقرار موفق، نشانی HTTPS سرویس را باز کنید و با `admin` و رمز تعیین‌شده وارد شوید.
6. برای APK، فایل workflow را به مسیر `.github/workflows/build-apk.yml` در ریشهٔ مخزن منتقل کنید و متغیر `VITE_API_URL` را روی نشانی HTTPS سرویس قرار دهید.

## امنیت
رمزهای واقعی را در فایل `.env` یا مخزن GitHub بارگذاری نکنید. کلید محرمانهٔ LiveKit فقط روی سرور بماند. پیش از استفادهٔ عملی، تماس و مجوزها را با چند دستگاه آزمایش کنید.
